面包水合率与加水量，算清每个配方

做面包最常卡住的一步，是「到底要放多少水、盐和酵母」。本发酵面团水量计算器用 baker's percentage（烘焙百分比）来算：以面粉重量为 100%，加水量 = 面粉 × 水合率%，盐 = 面粉 × 盐%，酵母 = 面粉 × 酵母%。只需输入面粉克数并拖动水合率，加水量、盐、干/鲜酵母与面团总重全部实时给出。内置 5 种水合预设（硬面 55% / 法棍 60% / 软包 65% / 吐司 72% / 恰巴塔 85%），干酵母一键切鲜酵母自动按 ×3 换算，盐、酵母、糖比例皆可微调，复制配方即可带走。

水合率（hydration %）定多少最常用？
新手最通用的区间是 60%–65%：法棍约 60%，软包餐包约 65%。偏干（≤58%）易整形、外壳厚脆；偏软（≥78%）黏软需折拌，适合恰巴塔 / 佛卡夏 / 汤种高水分面包。
干酵母和鲜酵母怎么换算？
一般按鲜酵母 ≈ 干酵母 × 3 克估算：例如需要 5g 干酵母时，换用鲜酵母约 15g。本计算器切到「鲜酵母」会自动按 ×3 给出用量。
盐加多少比较合适？
常规面包盐用量约为面粉的 1.5%–2%（默认 1.8%）。盐能增强面筋、抑制过度发酵、稳定风味，但不可省略——它是发酵节奏的关键变量。
baker's percentage 的「面团总重」是怎么算的？
以面粉重量为 100%，加水量 = 面粉 × 水合率%，盐 = 面粉 × 盐%，酵母 = 面粉 × 酵母%。面团总重 = 面粉 + 水 + 盐 + 酵母（+ 糖，若勾选）。输入面粉重量与水合率，计算器实时给出各项克数与总重。
